## 操作

- 下方時間軸、鍵盤 ← →，或手機左右滑動切換站點
- 直接點選場景裡的區域，或左下角小地圖
- 右上角：全景、自動導覽、全螢幕
- 網址加上站點名稱可直接開啟該站，例如 `#garden`、`#factory`、`#summary`

站點名稱：`entrance` `toolbox` `prompt` `research` `web` `factory` `sumeeko` `garden` `press` `ritual` `summary`

## 檔案

- `index.html`：整個網站（HTML、CSS、JavaScript 都在同一個檔案）
- `office.webp`：辦公室場景圖（放大用的 2 倍版本，九塊區域招牌已換成正確文字）
- `signs.svg`：九塊區域招牌的向量檔，網站放大時用它疊在場景上，文字不會模糊
- `office-bg.webp`：景深模糊背景
- `office-thumb.webp`：小地圖縮圖
- `og.jpg`：社群分享預覽圖
- `favicon.svg`、`favicon.ico`：分頁圖示（16／32／48）
- `apple-touch-icon.png`、`icon-192.png`、`icon-512.png`、`site.webmanifest`：加到手機主畫面時使用的圖示與設定
